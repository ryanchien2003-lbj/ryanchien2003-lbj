# Three AI portfolio projects

Each folder contains a standalone Streamlit app, dependencies, a README, and a resume bullet to adapt after running the project. All three run locally without an API key and use synthetic or fictional examples.

| Project | What it demonstrates |
| --- | --- |
| [Invoice Anomaly Review](invoice-anomaly-review/) | Unsupervised anomaly detection and review prioritization |
| [Support Ticket Triage](support-ticket-triage/) | NLP classification and human-review routing |
| [Operations Knowledge Assistant](operations-knowledge-assistant/) | Source-linked retrieval and evidence-based abstention |
